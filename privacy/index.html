whitcortex-backup privacy policy

Last updated: 1 November 2026

whitcortex-backup is a personal backup tool used by one person, its owner. This page describes what it does with Google user data.

What data it accesses

It uses one Google permission, drive.file. That limits it to files the app itself created in the owner's Google Drive. It cannot access any other file, and it doesn't access Gmail, contacts, calendar or any other Google service.

How the data is used

It uses the data only to store, list, verify and restore the owner's own backups. Backup data is encrypted on the owner's computer before upload.

Sharing

No data is shared with, sold to, or transferred to anyone. No data is used for advertising, analytics, profiling or training machine-learning models. The website uses no cookies, scripts or tracking.

Where data is stored

Backups stay in the owner's own Google Drive. The app has no servers of its own. Apart from a local cache on the owner's own computer, it keeps no other copy.

Retention and deletion

Backups are kept according to the owner's retention settings. To stop all access and delete the data:

  1. Revoke the app's access at myaccount.google.com/permissions.
  2. Delete the app's folder from Google Drive.

Google API Services User Data Policy

whitcortex-backup's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
