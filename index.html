whitcortex-backup

whitcortex-backup is a personal backup tool. It has one user, its owner. Nobody else can sign in to it, and it offers no service to the public.

It stores encrypted backup copies of the owner's files in the owner's own Google Drive.

Google access

It requests a single Google permission, https://www.googleapis.com/auth/drive.file. That scope gives it access only to files the app created itself in the owner's Drive. It cannot see, read or change any other file in the account.
